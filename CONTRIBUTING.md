# Contributing

ContextCommit is at an early stage. Issues, small focused pull requests, and
examples from real Agent workflows are welcome.

## Local checks

```bash
npm test
npm run check
```

Please keep the core local-first and dependency-light. A contribution should not
require an external LLM API for the base workflow.

By contributing, you agree that your contribution will be licensed under the
Apache License 2.0.
